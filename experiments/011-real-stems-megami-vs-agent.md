# 011 — Честный eval на реальных стемах: MEGAMI vs агентный фикс

## Материал

MedleyDB Sample (Zenodo 1438309, 416 МБ): `Phoenix_ScotchMorris` —
фолк-наигрыш «Lark On The Strand - Drummond Castle», 177 с, 44.1 кГц,
4 стема: `guitar, flute, violin, drums` + авторский `MIX.wav` (референс
баланса инженера). Лицензия MedleyDB — только исследовательское
использование, семпл распространяется свободно через Zenodo.

Порча: `flute -6 дБ` запечена в `sessions/scotch_flute_m6/`. Флейта —
лид-мелодия: тест «заметит ли агент не-вокальный лида».

Метры: flute −12.9 vs mix (до порчи было ≈ −7) — по DSP закопан явно.

## Результаты

Судья AudioJev, окно 60–72 с (одинаковое для всех), score-вопрос

|---|---|---|---|---|---|

`runaway_at_boundary: true`, остановился на +11.6 дБ.

## Выводы

1. **MEGAMI на честном материале покрывает правильный ответ.** 2 из 4
   сэмплов сели почти точно на баланс инженера (2.22–2.24 vs ref 2.26) —
   и это без знания порчи и референса. Распределение сэмплов осмысленное:
   {доминирует, закопан, сбалансирован ×2}. Гипотеза «MEGAMI = генератор
   кандидатов + внешний селектор» подтверждается сильнее, чем на
   затайленном corrupt6.

2. **Порча −6 дБ на этом материале судьёй почти не различима.**
   corrupt 2.06 vs ref 2.26 при conf 0.008–0.03 — внутри JND модели.
   DSP-метры при этом видят порчу однозначно (−12.9 дБ). Снова: метры —
   якорь, судья — вкус.

3. **Агентный фикс утёк за правильный ответ из-за калибровки target.**
   Дефолт target 2.48 откалиброван под прог-метал сессию; здесь ref =
   2.26. Фикс гнал вверх мимо истинных +6 дБ: на +9 дБ score уже равен
   референсному. Сама бисекция исправна — проблема в том, что «правильный
   баланс» имеет разный score на разном материале. Это и есть тот самый
   вкус-сдвиг, который надо калибровать per-session (например, спрашивать
   target у судьи на референсе/жанре, а не хардкодить).

4. **Баги, найденные и пофикшенные:** `render_for_judge` рендерил все
   177 с → 422 по max_prompt_tokens; теперь окно 12 с вокруг пикового
   RMS (cumsum, O(N) — первый вариант np.convolve вис на O(N·M)).

## Head-to-head

- MEGAMI: попадание в референс за 4 сэмпла + внешний отбор, ~2 мин GPU.
  Не «чинит» — сэмплирует; без селектора 25–50% промах.
- Агент: нашёл направление правильно, остановка зависит от калибровки
  target — на этой сессии перелетел до +11.6 дБ.

Гибрид очевиден: MEGAMI даёт N кандидатов, метры+судья выбирают лучший,
агент может дожать выбранный.
